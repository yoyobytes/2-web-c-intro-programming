# Tutorial de Cubo Rubik - Método para Principiantes

Un tutorial completo y detallado para aprender a resolver el cubo Rubik 3x3 usando el método para principiantes. Este proyecto está desarrollado en HTML puro como material educativo para cursos básicos de HTML.

## 📋 Descripción

Este proyecto contiene una página web educativa que enseña paso a paso cómo resolver un cubo Rubik utilizando el método más accesible para principiantes. Incluye notación de movimientos, algoritmos detallados y explicaciones claras para cada etapa del proceso.

## 🎯 Características

- **Tutorial Completo**: 7 pasos detallados para resolver el cubo
- **Notación Estándar**: Explicación de la notación internacional de movimientos (F, R, U, L, D, B)
- **Algoritmos Incluidos**: Todas las secuencias necesarias para cada paso
- **Formulario de Retroalimentación**: Encuesta de satisfacción al final del tutorial

## 🧩 Pasos del Tutorial

1. **Cruz Blanca**: Formar la cruz en la primera capa
2. **Esquinas Blancas**: Completar la primera capa completa
3. **Segunda Capa**: Insertar las aristas medias
4. **Cruz Amarilla**: Formar la cruz en la última capa
5. **Orientar Aristas Amarillas**: Alinear los colores laterales
6. **Posicionar Esquinas**: Colocar las esquinas en sus posiciones
7. **Orientar Esquinas**: Paso final para resolver el cubo

## 📝 Formulario de Retroalimentación

El tutorial incluye un formulario que recopila:
- Nivel de satisfacción del usuario
- Comprensión de la guía
- Éxito al resolver el cubo
- Paso más difícil
- Comentarios y sugerencias
- Información opcional del usuario (nombre, email, edad)

## 💼 Acerca de SIGO

Este proyecto forma parte de **SIGO** (Sistema de Instrucción para la Gestión Operativa), una iniciativa educativa para enseñar habilidades complejas de manera estructurada. Para conocer más sobre la viabilidad y visión del proyecto, consulta el [Elevator Pitch de SIGO](ELEVATOR_PITCH_SIGO.md).

## 📚 Recursos Adicionales

Para aprender más sobre el cubo Rubik:
- Practica cada paso individualmente antes de intentar resolver todo el cubo
- Busca videos complementarios para visualizar mejor los movimientos
- Una vez dominado este método, investiga métodos avanzados como CFOP o Roux
